# 三国题材原创身份卡牌游戏 — 设计文档（第一版）

> 原创作品：沿用身份牌游戏的通用骨架，武将技能、卡牌名称与效果均为原创。

## 一、已确认决定

| 项目 | 决定 |
|---|---|
| 方向 | 三国题材原创身份牌游戏 |
| 模式 | 单机：玩家 + 4 个 AI（以后扩展联网） |
| 平台 | 网页，TypeScript + React + Vite |
| 人数 | 固定 5 人：主公、忠臣、反贼×2、内奸 |
| 规则 | 通用骨架：体力 / 基础牌 / 锦囊 / 装备 / 距离 / 回合流程 |
| 武将 | 10 个 |
| AI | 基础 AI（按明确身份行动），以后加身份推理 |
| 美术 | 文字 + CSS 卡面，预留图片位置 |
| 完成标准 | 完整对局 + 游戏日志 + 选将界面 + 规则说明页，界面全中文 |

## 二、技术架构

```
src/
  engine/   规则引擎（纯 TS，不依赖 React，可移植到服务器）
  data/     卡牌、武将数据
  ai/       AI 决策
  ui/       React 界面
tests/      规则单元测试（Vitest）
```

- 引擎与界面分离：引擎在需要玩家决定时发出「请求」（选牌、选目标、是否响应），
  人类通过界面回答、AI 通过代码回答，接口一致。联网时把请求改走网络即可。
- 洗牌使用带种子的随机数，可完整复现对局。
- 规则引擎配单元测试。

## 三、基础规则

- **身份**：主公公开身份，体力上限 +1；其余身份阵亡时亮出。
- **胜负**：
  - 主公 + 忠臣：消灭所有反贼与内奸；
  - 反贼：主公阵亡；
  - 内奸：成为最后唯一存活者（主公阵亡时若场上只剩内奸，内奸胜，否则反贼胜）。
- **奖惩**：击杀反贼者摸 3 张牌；主公击杀忠臣，弃置所有手牌与装备。
- **回合**：准备 → 摸牌（2 张）→ 出牌 → 弃牌（手牌上限 = 当前体力）→ 结束。
- **距离**：座位顺/逆时针取较小值，坐骑修正；武器决定攻击范围（默认 1）。
- **濒死**：体力降至 0 时进入濒死，从当前回合角色开始依次询问是否使用【药】，
  无人救援则阵亡。
- 第一版不做判定 / 延时锦囊。

## 四、卡牌（约 80 张，带花色与点数）

### 基础牌
| 牌名 | 效果 |
|---|---|
| 【斩】 | 对攻击范围内一名角色造成 1 点伤害，出牌阶段限 1 张 |
| 【避】 | 抵消一张【斩】 |
| 【药】 | 出牌阶段回复自己 1 点体力（未受伤不可用）；或在任意角色濒死时对其使用 |

### 锦囊牌
| 牌名 | 效果 |
|---|---|
| 【调兵】 | 摸两张牌 |
| 【劫营】 | 弃置任意一名其他角色的一张牌 |
| 【策反】 | 获得距离 1 以内一名其他角色的一张牌 |
| 【檄文】 | 其他所有角色依次弃一张基础牌，否则受到 1 点伤害 |
| 【比武】 | 与目标轮流弃置【斩】（目标先），先不弃者受到 1 点伤害 |
| 【休整】 | 每名角色依次选择回复 1 点体力或摸一张牌 |
| 【识破】 | 抵消一张锦囊对一名目标的效果（可被【识破】再抵消） |

### 装备牌
| 装备 | 类型 | 效果 |
|---|---|---|
| 环首刀 | 武器·范围 2 | 你的【斩】结算完毕后，若目标手牌比你多，你摸一张牌 |
| 铁脊长枪 | 武器·范围 3 | 你可以将两张同颜色手牌当作【避】打出 |
| 镔铁大戟 | 武器·范围 3 | 使用【斩】时可额外指定与原目标相邻的一名角色（不受攻击范围限制） |
| 神臂弓 | 武器·范围 4 | 你不能对距离为 1 的角色使用【斩】 |
| 鱼鳞甲 | 防具 | 每回合第一次受到【斩】的伤害时，可弃一张基础牌防止此伤害（放弃也算用掉本回合机会） |
| 护心镜 | 防具 | 体力为 1 时受到伤害，此伤害 −1，然后弃置护心镜（只能保命一次） |
| 骐骥、骅骝 | 进攻马 | 你与其他角色距离 −1 |
| 青骢、黄骠 | 防御马 | 其他角色与你距离 +1 |

### 牌堆（80 张）
（M4 后为加快节奏调整：斩 26→31、避 15→12、药 8→6）
斩 31、避 12、药 6、调兵 4、劫营 4、策反 3、檄文 2、比武 3、休整 1、识破 4、装备 10。

### 结算细节
- 【识破】：锦囊对每个目标生效前，从当前回合角色起依次询问；被打出后再询问是否抵消该【识破】，直到无人打出。
- 【劫营】【策反】：选手牌时随机抽取，选装备时可指定。
- 【檄文】【休整】：从使用者起按座位顺序逐个结算，每个目标可单独被【识破】。
- 【休整】：满体力的角色只能摸牌。

## 五、武将（10 人）

| 势力 | 武将 | 体力 | 技能 |
|---|---|---|---|
| 魏 | 曹操 | 4 | **霸业**：你造成伤害后摸一张牌。主公技**号令**：你需要打出【避】而未打出时，其他魏势力角色可替你打出 |
| 魏 | 郭嘉 | 3 | **谋算**：你受到伤害后，观看牌堆顶 3 张，获得 1 张，其余任意顺序放回 |
| 魏 | 张辽 | 4 | **先登**：摸牌阶段可少摸 1 张，本回合你与其他角色距离视为 1 |
| 蜀 | 刘备 | 4 | **宽仁**：出牌阶段限一次，弃两张手牌令一名已受伤角色回复 1 点体力；其他角色回复体力时你摸一张牌。主公技**桃园**：其他蜀势力角色对你使用【药】时，你额外摸一张牌 |
| 蜀 | 诸葛亮 | 3 | **神算**：摸牌阶段改为观看牌堆顶 3 张获得其中 2 张，另一张置于牌堆底；你的锦囊不能被【识破】 |
| 蜀 | 赵云 | 4 | **七进**：每回合可多使用 1 张【斩】；你的【斩】被【避】抵消后摸一张牌 |
| 吴 | 孙权 | 4 | **坐断**：结束阶段若手牌少于体力，摸至体力值。主公技**江东**：吴势力角色阵亡时你回复 1 点体力 |
| 吴 | 周瑜 | 3 | **火计**：出牌阶段限一次，弃两张同花色手牌，对一名角色造成 1 点伤害 |
| 群 | 吕布 | 4 | **骁勇**：攻击范围 +1；你的【斩】造成伤害后，弃置目标一张装备 |
| 群 | 貂蝉 | 3 | **惑心**：出牌阶段限一次，选两名其他角色（后者须在前者攻击范围内），前者须对后者使用一张【斩】，否则交给你一张手牌 |

### 技能结算细节
- 主公技只有该武将担任主公时生效。
- 【先登】只改变张辽到其他角色的距离，不改变别人到张辽的距离（注意：配合【神臂弓】时将无法使用【斩】）。
- 【惑心】中前者使用的【斩】按正常【斩】结算（可被【避】、触发武器效果），不占用其出【斩】次数。
- 【骁勇】仅在【斩】实际造成伤害（未被防具防止）后触发。

## 六、基础 AI（`src/ai/basic.ts`）

AI 只使用自己视角可见的信息，不作弊。

- **敌友判断**
  - 已知身份：自己、主公、阵亡者。
  - 身份排除：未知者只可能是某一种身份时直接认定（例如反贼全灭后，忠臣认定剩下的未知者是内奸）。
  - 公开敌对记录（记仇）：谁对谁使用过【斩】、劫营、策反、比武、火计、惑心。
    - 主公：攻击过自己的人是敌人。
    - 忠臣：攻击过主公或自己的人是敌人。
    - 反贼：主公是敌人且优先集火主公；攻击主公的人视为同伴；攻击自己或同伴的人是敌人。
    - 内奸：第一个角色阵亡前按兵不动（被攻击会还手，主公濒死会救）。
      - 第一个阵亡的是忠臣 → 帮主公，攻击打过主公的人。
      - 第一个阵亡的是反贼 → 帮反贼，攻击主公和疑似忠臣（打过反贼的人）；但主公体力 ≤4（`LORD_DANGER_HP`）或反贼人数追平主公方时，转回帮主公。
      - 只剩主公时攻击主公；最后单挑时不救主公。
- **出牌顺序**：装备（空槽；武器按射程评分，人少时不用神臂弓）→【药】（濒危或手牌溢出）→【调兵】/【休整】→ 主动技能 → 攻击锦囊 → 【斩】（优先体力最低的敌人）。
- **响应**：有【避】就出；只救自己和队友；【识破】只用于保护队友免受有害锦囊。
- **平衡统计**：`npm run simulate -- 局数 回合上限` 统计 AI 对战胜率与回合数。
  - 当前（2000 局）：主公方 52.3%、反贼 33.9%、内奸 13.8%；回合数中位数 65。目标反贼 30%–35%。

## 七、里程碑

1. **M1 规则引擎**：牌堆、回合流程、基础牌、距离、伤害/濒死、胜负判定 + 单元测试
2. **M2 卡牌补全**：全部锦囊与装备
3. **M3 武将技能**：10 个武将
4. **M4 AI**：4 个 AI 自动打完一局
5. **M5 界面**：牌桌、手牌交互、游戏日志、选将界面、规则说明页

## 八、界面（M5）

- 主菜单 → 开始游戏 / 规则说明（规则页的卡牌与武将列表直接读取数据文件，改数据会自动同步）。
- 牌桌：你在下方，其余 4 名电脑按座位顺序环绕；显示身份（已知时）、体力、手牌数、装备、技能、与你的距离和是否在攻击范围内。
- 操作：点手牌 → 点目标座位 → 「确定」；技能按钮 → 选牌/目标 → 「确定」；被询问时选牌后「确定」或「不出」；选将、劫营、谋算等用弹窗。
- 右侧为游戏日志；可调 AI 速度（快/中/慢）；结束时显示全部身份。

### 替换美术素材
把图片放进 `public/` 目录，然后在数据文件里填写路径即可，界面会自动显示图片代替文字：
- 卡面：`src/data/cards.ts` 中对应卡牌加 `image: '/cards/zhan.png'`
- 武将立绘：`src/data/generals.ts` 中对应武将加 `image: '/generals/caocao.png'`
