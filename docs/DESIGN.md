# 三国题材原创身份卡牌游戏 — 设计文档（第一版）

> 原创作品：沿用身份牌游戏的通用骨架，武将技能、卡牌名称与效果均为原创。

## 一、已确认决定

| 项目 | 决定 |
|---|---|
| 方向 | 三国题材原创身份牌游戏 |
| 模式 | 单机：玩家 + 4 个 AI（以后扩展联网） |
| 平台 | 网页，TypeScript + React + Vite |
| 人数 | 固定 5 人：主公、忠臣、反贼×2、内奸 |
| 规则 | 通用骨架：体力 / 基础牌 / 锦囊 / 装备 / 距离 / 回合流程 |
| 武将 | 20 个（第一批 10 个 + 第二批 6 个 + 第三批 4 个） |
| AI | 基础 AI（按明确身份行动），以后加身份推理 |
| 美术 | 文字 + CSS 卡面，预留图片位置 |
| 完成标准 | 完整对局 + 游戏日志 + 选将界面 + 规则说明页，界面全中文 |

## 二、技术架构

```
src/
  engine/   规则引擎（纯 TS，不依赖 React，可移植到服务器）
  data/     卡牌、武将数据
  ai/       AI 决策
  ui/       React 界面
tests/      规则单元测试（Vitest）
```

- 引擎与界面分离：引擎在需要玩家决定时发出「请求」（选牌、选目标、是否响应），
  人类通过界面回答、AI 通过代码回答，接口一致。联网时把请求改走网络即可。
- 洗牌使用带种子的随机数，可完整复现对局。
- 规则引擎配单元测试。

## 三、基础规则

- **身份**：主公公开身份，体力上限 +1；其余身份阵亡时亮出。
- **胜负**：
  - 主公 + 忠臣：消灭所有反贼与内奸；
  - 反贼：主公阵亡；
  - 内奸：成为最后唯一存活者（主公阵亡时若场上只剩内奸，内奸胜，否则反贼胜）。
- **奖惩**：击杀反贼者摸 3 张牌；主公击杀忠臣，弃置所有手牌与装备。
- **回合**：准备 → 摸牌（2 张）→ 出牌 → 弃牌（手牌上限 = 当前体力）→ 结束。
- **距离**：座位顺/逆时针取较小值，坐骑修正；武器决定攻击范围（默认 1）。
- **濒死**：体力降至 0 时进入濒死，从当前回合角色开始依次询问是否使用【药】，
  无人救援则阵亡。
- 第一版不做判定 / 延时锦囊。

## 四、卡牌（84 张，带花色与点数）

### 基础牌
| 牌名 | 效果 |
|---|---|
| 【斩】 | 对攻击范围内一名角色造成 1 点伤害，出牌阶段限 1 张 |
| 【避】 | 抵消一张【斩】 |
| 【药】 | 出牌阶段回复自己 1 点体力（未受伤不可用）；或在任意角色濒死时对其使用 |

### 锦囊牌
| 牌名 | 效果 |
|---|---|
| 【调兵】 | 摸两张牌 |
| 【劫营】 | 弃置任意一名其他角色的一张牌 |
| 【策反】 | 获得距离 1 以内一名其他角色的一张牌 |
| 【檄文】 | 其他所有角色依次弃一张基础牌，否则受到 1 点伤害 |
| 【比武】 | 与目标轮流弃置【斩】（目标先），先不弃者受到 1 点伤害 |
| 【休整】 | 每名角色依次选择回复 1 点体力或摸一张牌 |
| 【识破】 | 抵消一张锦囊对一名目标的效果（可被【识破】再抵消） |

### 牌堆（84 张）

斩 31、避 12、药 6、调兵 4、劫营 4、策反 3、檄文 2、比武 3、休整 1、识破 4、断粮 2、军令 2、装备 10。

### 结算细节
- 【识破】：锦囊对每个目标生效前，从当前回合角色起依次询问；被打出后再询问是否抵消该【识破】，直到无人打出。
- 【劫营】【策反】：选手牌时随机抽取，选装备时可指定。
- 【檄文】【休整】：从使用者起按座位顺序逐个结算，每个目标可单独被【识破】。
- 【休整】：满体力的角色只能摸牌。
- 判定区（`Player.judge`，公开）：延时锦囊使用时不能被【识破】，置于目标判定区，同名最多一张；劫营、策反不能拿判定区的牌；阵亡时一并弃置。
- 判定：准备阶段（华佗【养生】之后）按放入顺序逐张结算。每张判定前从当前角色起询问【识破】（抵消则直接弃置）；否则翻开牌堆顶一张为判定牌，结算完两张都进弃牌堆。结算完毕前延时锦囊仍留在判定区，保证牌数守恒。
- 与【神算】：诸葛亮使用的延时锦囊不能被【识破】，并触发「每回合第一次使用锦囊摸一张」；诸葛亮中【断粮】时改为观看 3 张获得 1 张。张辽【先登】时再少摸 1 张（共摸 0 张）。
- 公开行为：使用延时锦囊记敌对 0.6（`HOSTILE_WEIGHT.delay`）；替人识破延时锦囊记帮助（与有害锦囊相同）。
- AI：【军令】给威胁最大的敌人（手牌数 + 武器射程 + 多【斩】武将）；【断粮】给体力高、手牌少的敌人；反贼都优先主公。
- 统计（2000 局）：每局平均使用延时锦囊 7.2 张，判定 6.1 次，生效 3.7 次，被识破约 1 次。

### 技能结算细节
- 主公技只有该武将担任主公时生效。
- 【先登】的多 1 张【斩】和伤害摸牌只在张辽自己发动的回合生效（被惑心逼出的【斩】不算）。
- 【先登】只改变张辽到其他角色的距离，不改变别人到张辽的距离（注意：配合【神臂弓】时将无法使用【斩】）。
- 【惑心】中前者使用的【斩】按正常【斩】结算（可被【避】、触发武器效果），不占用其出【斩】次数。
- 【骁勇】仅在【斩】实际造成伤害（未被防具防止）后触发。
- 【韬晦】只看司马懿自己回合内造成的伤害；对自己造成的伤害不算。
- 【过关】回合开始时判断；关羽自己的回合中人数降到 3 人时，本回合立即多 1 次【斩】。
- 【持重】包括用【铁脊长枪】将两张牌当【避】打出；替别人出【避】（号令）不算。
- 【锦帆】与【骁勇】一样，需要【斩】实际造成伤害且目标存活、有手牌。

## 六、基础 AI（`src/ai/basic.ts`）

AI 只使用自己视角可见的信息，不作弊。

- **敌友判断**
  - 已知身份：自己、主公、阵亡者。
  - 身份排除：未知者只可能是某一种身份时直接认定（例如反贼全灭后，忠臣认定剩下的未知者是内奸）。优先于倾向分。
  - 公开行为记录（引擎记录，所有人可见，玩家的行为也一样被记录）：
    - 敌对 `hostility`：【斩】、火计、比武、惑心发起者 1.0；劫营、策反 0.6；被惑心逼出的【斩】0.5。
    - 帮助 `help`：濒死时对别人用【药】1.5；宽仁 1.0；【识破】替人挡掉有害锦囊 1.0；号令替主公出【避】1.0。
    - 【识破】挡掉别人的有益锦囊记为敌对 1.0；反【识破】让锦囊重新生效，按效果记帮助/敌对 0.5。
  - **身份倾向分**（−1 偏反 … +1 偏忠，单轴，不单独识别内奸），每个 AI 从自己视角连锁推理：
    - 锚点：主公 +1；阵亡者按真实身份（忠 +1、反 −1、内奸 0）；可由身份排除推出的人；自己（忠臣 +1、反贼 −1，内奸自己不当锚点）。
    - 其他人：分数 = Σ（对 t 的帮助 − 对 t 的敌对）× t 的当前分数，迭代 8 轮，每轮限制在 ±1 并与上轮取平均。与行为先后无关，不会因一次误判越滚越大。
    - 阈值 `LEAN_THRESHOLD = 0.4`：主公、忠臣把分数 < −0.4 的当敌人、> 0.4 的当队友；反贼相反。看不出立场但打过自己的人会被还手。
  - **内奸嫌疑分**（2026-11-06，第二阶段，参数在 `SUSPICION_TUNING`）：把未知者的行为分成「帮主公方」（帮偏忠的人、打偏反的人）和「帮反贼方」（帮偏反的人、打偏忠的人），按目标的倾向分加权，嫌疑分 = 两者中较小的一方。身份排除确定内奸不在未知者中时为 0。
    - 嫌疑分 ≥ 1.0 为疑似内奸：主公、忠臣、反贼原本会当队友的改成中立（不救、不给牌、不替他挡锦囊），原本是敌人的不变。未知者的倾向分到不了 ±1，所以一次攻击略低于阈值。
    - 诊断 `npx vite-node scripts/diag-suspicion.ts 局数`（环境变量 `SUSPICION='{"threshold":0.5}'` 可改参数）：真内奸被认出 33%（偏反时 80%，偏忠时 20%）；忠臣被误判 2.5%、反贼 0.7%。
    - 胜率几乎不变（10000 局：改前 62.3 / 26.4 / 11.4，改后 62.5 / 26.0 / 11.5；阈值 0.5 时 62.3 / 26.0 / 11.7）：内奸多数时间按兵不动（倾向分接近 0，本来就是中立），而「队友 → 中立」只影响救人、宽仁、识破等少数动作。保留作为以后伪装、界面显示推理的基础。
  - 内奸策略（参数在 `RENEGADE_TUNING`）：第一个角色阵亡前按兵不动（被攻击会还手，主公濒死会救）。
    - 第一个阵亡的是忠臣 → 帮主公，攻击疑似反贼。
    - **平衡**（2026-11-04）：反贼只剩 1 人且忠臣还活着时，攻击忠臣、不打最后一个反贼，反贼濒死时用【药】救他，避免被主公 + 忠臣 2 打 1；主公只剩 1 点体力时转回帮主公。
      只剩两个未知者（必定一忠一反）时，比较两人的倾向分（相同则看谁打主公多）认定忠反。
    - **抢人头**：优先用【斩】/【比武】补刀体力 ≤1 的（疑似）反贼，拿 3 张奖励牌；但不抢平衡模式下最后一个反贼。
    - 旧的「帮反贼」模式（主公体力 ≤4 `LORD_DANGER_HP` 时转回）只在关闭平衡时生效。
    - 只剩主公时攻击主公；最后单挑时不救主公。
- **出牌顺序**：装备（空槽；武器按射程评分，人少时不用神臂弓）→【药】（濒危或手牌溢出）→【调兵】/【休整】→ 主动技能 → 攻击锦囊 → 【斩】（优先体力最低的敌人）。
- **响应**：有【避】就出；只救自己和队友；【识破】只用于保护队友免受有害锦囊。
- **平衡统计**：`npm run simulate -- 局数 回合上限` 统计 AI 对战胜率与回合数。
  - 当前（2000 局，加入身份推理后）：主公方 57.5%、反贼 31.6%、内奸 9.8%；回合数中位数 55。目标反贼 30%–35%。
  - 加入身份推理前：主公方 51.4%、反贼 33.9%、内奸 12.8%；回合数中位数 64。
  - 加入第二批武将后（2000 局）：主公方 57.4%、反贼 29.4%、内奸 12.9%；回合数中位数 54。
  - 调整老武将后（2000 局）：主公方 61.9%、反贼 27.3%、内奸 10.9%。所有武将按身份校正后都在 ±9% 以内。
    主公候选里强武将变多（诸葛亮最常当主公），主公方变强，反贼低于 30% 目标，待处理。
  - 内奸加入平衡 + 抢人头后（2000 局）：主公方 59.1%、反贼 28.4%、内奸 12.5%；回合数中位数 55。
    `npx vite-node scripts/diag-renegade.ts 局数` 统计内奸的死因与结局，可用环境变量 `TUNING='{"stealKills":false}'` 对比参数。
    对比（各 2000 局，内奸胜率）：不平衡不抢 10.9%；平衡但主公濒危不转回 11.7%（反贼升到 36%）；平衡 + 主公 1 血转回 12.5%；去掉抢人头约 −1.5%。
    平衡只部分解决问题：内奸打忠臣、救反贼都执行到了，但主公 + 忠臣在 2 打 2 中仍占优，内奸死于"主公 + 忠臣 + 内奸"局面的局数从约 50% 降到约 37%。
  - 加强张辽后（2000 局）：主公方 59.7%、反贼 28.4%、内奸 11.9%（与之前在误差内）。
  - 调整赵云、诸葛亮、华佗后（2000 局）：主公方 60.6%、反贼 27.7%、内奸 11.7%；回合数中位数 55。

  - 加入延时锦囊后（10000 局）：主公方 61.4%、反贼 26.7%、内奸 11.9%（加入前 62.5 / 26.0 / 11.5）；回合数中位数 54。20 名武将按身份校正后都在 ±6% 以内（司马懿 +5.3% 最高，郭嘉 −4.2% 最低）。
  - 选将：AI 按偏好表选将，排名加 0~8 的确定性扰动（`PICK_JITTER`），否则排最后的武将永远不会被选（以前的张辽）。张辽排在第 9 位。内奸另有偏好表（关羽、刘备、司马懿、赵云、华佗，按模拟中内奸胜率排序）。

## 八、界面（M5）

- 主菜单 → 开始游戏 / 规则说明（规则页的卡牌与武将列表直接读取数据文件，改数据会自动同步）。
- 牌桌：你在下方，其余 4 名电脑按座位顺序环绕；显示身份（已知时）、体力、手牌数、装备、技能、与你的距离和是否在攻击范围内。
- 操作：点手牌 → 点目标座位 → 「确定」；技能按钮 → 选牌/目标 → 「确定」；被询问时选牌后「确定」或「不出」；选将、劫营、谋算等用弹窗。
- 右侧为游戏日志；可调 AI 速度（快/中/慢）；结束时显示全部身份。
- 场上可视化（2026-11-05，不阻塞游戏流程，特效约 0.8 秒淡出）：
  - 引擎日志条目带可选结构化事件 `LogEntry.event`（turn / use / discard / damage / recover / dying / death），只用于界面展示，不影响规则。
  - 牌桌中央「出牌区」只显示最近一次结算中的全部牌（例如【斩】+ 响应的【避】；【檄文】则包括所有人响应的牌），出牌事件带 `start` 标记表示新结算开始，并标注「谁 → 谁」；新回合开始时清空。
  - 出牌或技能指定目标时画指向线（技能为紫色）；受伤的座位闪红并飘出 −N，回复的闪绿并飘出 +N。
  - 濒死角色的座位边框闪红，中央显示「某某 濒死，求【药】！」；轮到你救人时提示栏变成红色；阵亡时有盖章动画。

- 信息查看（2026-11-05）：
  - 悬浮提示（`src/ui/tooltip.tsx`）：鼠标移到牌、装备、技能名上立即显示说明卡（牌名、类型/槽位/攻击范围、花色点数、效果），会避开屏幕边缘；代替浏览器自带的 `title` 提示。
  - 武将详情（`src/ui/inspect.tsx`）：每个座位和自己的区域都有「ⓘ」按钮，点开后显示势力、体力、手牌数、已知身份、全部技能（主公技会标注是否生效）和装备说明。点 ⓘ 不会触发选目标。
  - 暂停：会话配置 `pauseOnInspect` 为 true 时（单机对 AI），打开详情会通过 `PauseGate` 暂停 AI 的下一次决策，关闭后继续。以后联网与真人对局时应设为 false。
  - 日志筛选：全部 / 与我相关（事件涉及你的座位，或文字中出现「你」；只保留有相关条目的回合标题）/ 本回合。

- 快捷键与自动选中（2026-11-06，`src/ui/hotkeys.ts`）：
  - 自动选中：出牌时只有一个合法目标就自动选中（镔铁大戟的额外目标仍手动）；技能第一目标唯一时自动选中；响应时只有一张能出的牌就预先选中。都仍需「确定」。
  - 按键：空格/Enter 确定；Esc 取消选择，无选择时「不出」；1–9、0 选第 N 张手牌（弹窗中选第 N 项）；E 结束出牌；Q、W 发动第 1、2 个技能；Tab 切换目标。
  - 按键提示用 `data-key` + CSS `::after` 显示在按钮上（不改变按钮文字），手牌右下角显示数字。
  - 打开武将详情时只有 Esc（关闭面板）生效；带修饰键或长按重复的按键忽略；按键前先让按钮失去焦点，避免空格同时触发按钮点击。

- 对局回放与战绩（2026-11-06）：
  - 记录（`src/engine/record.ts`）：引擎是确定性的，只保存随机种子 + 所有人按顺序的全部回答（`RecordingController` 包在每个控制器外面；AI 的回答也记，AI 改了旧记录照样能看）。每局约 8 KB（中位数，最长约 27 KB）。
  - 回放：用 `ReplayController` 按顺序喂回答重跑一局，每写一条日志就存一份完整局面快照（所有身份、手牌、装备、判定区）。回答座位对不上、记录用完、结局或日志条数与原局不同时，提示「与当前版本不兼容」并显示已重现的部分。规则改动导致旧记录无法重现时递增 `RECORD_VERSION`。
  - 存储（`src/ui/storage.ts`，localStorage）：最近 20 局记录（最新在前）+ 累计战绩（总场次、按身份、按武将；可清空，不影响记录）。只保存正常打完的局。
  - 回放界面（`src/ui/ReplayScreen.tsx`）：牌桌布局同对局，所有身份与手牌公开；出牌区与指向线照常显示（大步跳转时只为最后 3 条生成特效）；右侧日志高亮当前步、点击跳转。控制：开头 / 上一回合 / 上一步 / 播放 / 下一步 / 下一回合 / 结尾、进度条、播放速度。快捷键：← → 单步，空格播放/暂停，PageUp/PageDown 按回合，Home/End，Esc 返回。
  - 入口：主菜单「对局记录」（`src/ui/RecordsScreen.tsx`：战绩 + 最近对局列表）；结束弹窗「查看回放」。
