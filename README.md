# 三国身份牌

一款三国题材的**原创**身份卡牌网页游戏：五人身份局，你与四名电脑 AI 对战。

> 沿用身份牌游戏的通用骨架（体力、基础牌、锦囊、装备、距离、回合流程），武将技能、卡牌名称与效果均为原创设计。

## 特色

- **五人身份局**：主公、忠臣、反贼 ×2、内奸，身份隐藏，阵亡后亮出
- **16 名原创技能武将**：魏（曹操、郭嘉、张辽、司马懿）、蜀（刘备、诸葛亮、赵云、关羽）、吴（孙权、周瑜、陆逊、甘宁）、群（吕布、貂蝉、华佗、张角）
- **80 张牌**：3 种基础牌、7 种锦囊、10 件装备（武器、防具、坐骑）
- **基础 AI**：只使用自己视角可见的信息，不偷看手牌与身份
- **全中文界面**：选将、牌桌、游戏日志、规则说明页
- **可复现**：洗牌使用带种子的随机数，任何一局都能完整重现

## 快速开始

需要 [Node.js](https://nodejs.org/) 20 或更高版本。

```bash
git clone https://github.com/Maknight233/Sanguosha.git
cd Sanguosha
npm install
npm run dev
```

然后在浏览器打开终端显示的地址（默认 <http://localhost:5173/>）。

## 怎么玩

- **出牌**：点击手牌 → 点击高亮的目标座位 → 「确定」
- **技能**：点击「发动【技能名】」→ 选择手牌和目标 → 「确定」
- **响应**：被询问时选牌后点「确定」，或点「不出」
- **座位信息**：每个座位显示已知身份、体力、手牌数、装备、技能，以及与你的距离、是否在你的攻击范围内
- 右侧为游戏日志；可调节 AI 速度（快 / 中 / 慢）

完整规则见游戏内「规则说明」页，或 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 类型检查并构建生产版本到 `dist/` |
| `npm test` | 运行全部测试 |
| `npm run typecheck` | 只做类型检查 |
| `npm run simulate -- 1000 5000` | 让 5 个 AI 对战 1000 局（单局回合上限 5000），统计各阵营胜率与回合数 |

## 项目结构

```
src/
  engine/       规则引擎（纯 TypeScript，不依赖 React，可移植到服务器做联网）
    game.ts       对局流程、出牌、响应、伤害、濒死、胜负判定
    types.ts      类型定义与「请求 → 回答」控制器接口
    rng.ts        带种子的随机数
  data/         数据：卡牌（cards.ts）与武将（generals.ts）
  ai/
    basic.ts      基础 AI
    random.ts     随机合法操作（用于压力测试）
  ui/           React 界面
tests/          单元测试、AI 测试、界面端到端测试（Vitest + jsdom）
scripts/        AI 对战统计脚本
docs/DESIGN.md  设计文档（规则、卡牌、武将、AI、结算细节）
```

### 架构要点

引擎在需要玩家做决定时发出「请求」（选牌、选目标、是否响应……），由控制器回答：人类玩家通过界面回答，AI 通过代码回答，两者实现同一个 `Controller` 接口。引擎会校验每个回答，非法操作会被忽略。将来做联网时，只需把请求改为通过网络发送。

## 扩展

### 替换美术素材

当前卡面与武将立绘都是文字占位。把图片放进 `public/` 目录，再在数据文件中填写路径即可：

```ts
// src/data/cards.ts
{ key: 'zhan', name: '斩', ..., image: '/cards/zhan.png' }

// src/data/generals.ts
{ key: 'caocao', name: '曹操', ..., image: '/generals/caocao.png' }
```

### 调整平衡

- 牌堆构成：`src/data/cards.ts` 中的 `DECK_SPEC`
- 内奸 AI 转回帮主公的体力门槛：`src/ai/basic.ts` 中的 `LORD_DANGER_HP`
- 调整后用 `npm run simulate` 查看胜率变化
