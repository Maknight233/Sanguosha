# 三国身份牌

一款三国题材的**原创**身份卡牌网页游戏：5–8 人身份局或 1v1 对决，你与电脑 AI 对战。

> 沿用身份牌游戏的通用骨架（体力、基础牌、锦囊、装备、距离、回合流程），武将技能、卡牌名称与效果、美术均为原创设计。

## 特色

- **5–8 人身份局**：主公、忠臣、反贼、内奸，身份隐藏，阵亡后亮出；7、8 人局内奸有身份技【隐忍】
- **1v1 对决**：两人单挑，先手第一回合少摸 1 张，双方各从 3 名武将中选 1 名（23 名武将可选）
- **40 名原创技能武将**（每个势力 10 名），含判定、装备、受伤触发、救援、拼点等主题
  - 魏：曹操、郭嘉、张辽、司马懿、典韦、荀彧、曹仁、夏侯惇、庞德
  - 蜀：刘备、诸葛亮、赵云、关羽、黄忠、魏延、张飞、马超、糜竺
  - 吴：孙权、周瑜、陆逊、甘宁、鲁肃、吕蒙、太史慈、周泰、大乔
  - 群：吕布、貂蝉、华佗、张角、董卓、于吉、公孙瓒、华雄、蔡文姬
- **89 张牌**：3 种基础牌、10 种锦囊（含【断粮】【军令】【天雷】3 种延时锦囊与判定）、13 件装备（5 武器、4 防具、4 坐骑）
- **会推理、会伪装的 AI**：只用自己视角可见的信息，根据公开行为推测身份、怀疑内奸；反贼可能开局潜伏。难度分简单 / 普通
- **读局**：对局中可显示旁观者视角的身份推测；回放时可切换到任意 AI 的视角
- **对局回放与战绩**：自动保存最近 20 局，可逐步回放；累计战绩按身份、武将、人数、难度统计；支持导出 / 导入单局回放与全量备份
- **水墨印章风美术**：武将头像、卡面、背景与动效（墨点受伤、墨晕回复、毛笔指向线、阵亡印章）全部由程序生成，不依赖图片文件
- **音效**：Web Audio 现场合成，可开关、调音量
- **上手友好**：新手情境提示、规则速查、悬浮说明卡、武将详情、快捷键
- **手机可玩**：横屏紧凑牌桌，长按牌 / 装备 / 技能看说明，功能按钮收进右上角「☰」；竖屏会提示横过手机
- **新手教程**：第一次打开会问要不要先打一局约 3 分钟的教学局，一步步教出牌、装备、锦囊和响应；主菜单随时可以再看
- **平局**：牌堆第 7 次被摸光仍未分出胜负时按平局处理，不计入战绩
- **全中文界面**，洗牌使用带种子的随机数，任何一局都能完整重现

## 快速开始

需要 [Node.js](https://nodejs.org/) 20 或更高版本。

```bash
git clone https://github.com/Maknight233/Sanguosha.git
cd Sanguosha
npm install
npm run dev
```

然后在浏览器打开终端显示的地址（默认 <http://localhost:5173/>）。

## 怎么玩

在主菜单选择人数（5–8 人身份局，或 1v1）和 AI 难度，开始游戏后选将。

- **出牌**：点击手牌 → 点击高亮的目标座位 → 「确定」（只有一个合法目标时会自动选中）
- **技能**：点击「发动【技能名】」→ 选择手牌和目标 → 「确定」
- **响应**：被询问时选牌后点「确定」，或点「不出」；群体锦囊可以点「不识破」，本张牌剩余目标不再询问
- **座位信息**：每个座位显示已知身份、体力、手牌数、装备、判定区、技能，以及与你的距离、是否在你的攻击范围内；鼠标移到牌或技能上显示说明，点「ⓘ」看武将详情
- **右侧栏**：出牌记录、读局、规则速查、AI 速度（快 / 中 / 慢）、音效

### 快捷键

| 按键 | 作用 |
|---|---|
| 空格 / Enter | 确定 |
| Esc | 取消选择；没有选择时「不出」；关闭面板 |
| 1–9、0 | 选第 N 张手牌（弹窗中选第 N 项） |
| Tab | 切换目标 |
| Q、W、R、T | 发动第 1–4 个技能 |
| E | 结束出牌 |
| L | 出牌记录（打开时游戏暂停） |
| I | 读局开关 |
| F1 | 规则速查（打开时游戏暂停） |

回放界面：← → 单步，空格播放 / 暂停，PageUp / PageDown 按回合跳转，Home / End 到开头 / 结尾，Esc 返回。

完整规则见游戏内「规则说明」页，或 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 类型检查并构建生产版本到 `dist/` |
| `npm test` | 运行全部测试 |
| `npm run typecheck` | 只做类型检查 |
| `npm run simulate -- 2000 5000` | 让 5 个 AI 对战 2000 局（5 人局，单局回合上限 5000），统计各阵营胜率与回合数 |

其他统计脚本用 `npx vite-node` 运行，用法写在各文件开头：

| 脚本 | 作用 |
|---|---|
| `scripts/general-stats.ts` | 每个武将按身份校正后的胜率（`PLAYERS=5…8` 指定人数，可并行） |
| `scripts/duel-stats.ts` | 1v1：先手 / 后手胜率、回合数、每名武将的胜率 |
| `scripts/difficulty.ts` | 两种 AI 难度混合对局，比较同身份下的胜率 |
| `scripts/disguise.ts` | 读局（旁观者视角）的身份识别准确率 |
| `scripts/comeback.ts` | 新卡牌对胜率与翻盘率的影响 |
| `scripts/diag-suspicion.ts`、`scripts/diag-renegade.ts` | 内奸嫌疑判断与内奸死因诊断 |

## 项目结构

```
src/
  engine/       规则引擎（纯 TypeScript，不依赖 React，可移植到服务器做联网）
    game.ts       对局流程、出牌、响应、判定、伤害、濒死、胜负判定、技能
    types.ts      类型定义与「请求 → 回答」控制器接口
    record.ts     对局记录与回放（种子 + 全部回答）
    rng.ts        带种子的随机数
  data/         数据：卡牌（cards.ts）与武将（generals.ts）
  ai/
    basic.ts      基础 AI：身份推理、内奸策略、伪装、难度
    random.ts     随机合法操作（用于压力测试）
  ui/           React 界面
    GameScreen / ReplayScreen / RecordsScreen / RulesPage   对局、回放、记录与战绩、规则页
    art.tsx、effects.tsx、bg/    程序生成的头像、卡面、动效与背景
    sound.ts      音效合成
    storage.ts、transfer.ts      本地存储与导出 / 导入
    hotkeys.ts、tips.ts、help.tsx、tooltip.tsx、inspect.tsx、infer.tsx
                  快捷键、新手提示、规则速查、悬浮说明、武将详情、读局
    tutorial.ts   新手教学局（固定剧本）
tests/          单元测试、AI 测试、界面端到端测试（Vitest + jsdom）
scripts/        AI 对战统计与诊断脚本
docs/DESIGN.md  设计文档（开头「现状速览」是当前事实；后面按开发顺序记录规则、AI、各项改动的数据依据）
```

### 架构要点

- 引擎在需要玩家做决定时发出「请求」（选牌、选目标、是否响应……），由控制器回答：人类玩家通过界面回答，AI 通过代码回答，两者实现同一个 `Controller` 接口。引擎会校验每个回答，非法操作会被忽略。将来做联网时，只需把请求改为通过网络发送。
- 引擎是确定性的：一局记录只保存随机种子和所有人按顺序的回答，回放时重跑一遍。规则改动使旧记录无法重现时递增 `RECORD_VERSION`（`src/engine/record.ts`），旧记录会提示「与当前版本不兼容」。
- 记录、战绩与各项设置都存在浏览器 localStorage 中；换浏览器或设备请用「对局记录」页的导出 / 导入。

## 扩展

### 新增武将或卡牌

1. 在 `src/data/generals.ts` 或 `src/data/cards.ts` 中加数据（卡牌还要加进 `DECK_SPEC`），在 `src/engine/game.ts` 中实现效果
2. 在 `src/ui/art.tsx` 的 `GENERAL_MOTIF` / `CARD_MOTIF` 中指定纹样（`tests/art.test.tsx` 会检查遗漏）
3. 规则说明页直接读取数据文件，会自动同步

### 替换美术素材

默认的头像与卡面由程序生成。想换成图片时，把图片放进 `public/` 目录，再在数据文件中填写路径即可：

```ts
// src/data/cards.ts
{ key: 'zhan', name: '斩', ..., image: '/cards/zhan.png' }

// src/data/generals.ts
{ key: 'caocao', name: '曹操', ..., image: '/generals/caocao.png' }
```

### 调整平衡

- 牌堆构成：`src/data/cards.ts` 中的 `DECK_SPEC`
- 各人数的身份分配与主公体力加成：`src/engine/game.ts` 中的 `ROLE_TABLE`、`LORD_BONUS`
- 技能参数：`src/engine/game.ts` 中的 `SKILL_TUNING`
- AI 参数：`src/ai/basic.ts` 中的 `LORD_DANGER_HP`、`RENEGADE_TUNING`、`SUSPICION_TUNING`、`DISGUISE_TUNING`
- 调整后用 `npm run simulate` 和 `scripts/general-stats.ts` 查看胜率变化

## 平衡数据

普通难度 AI 对战，各 10000 局（2026-11-12；6、8 人局的内奸为两名合计）：

| 人数 | 主公方 | 反贼 | 内奸 | 平局 | 回合数中位数 |
|---|---|---|---|---|---|
| 5 | 55.8% | 33.1% | 11.0% | 0.1% | 49 |
| 6 | 49.0% | 26.2% | 24.5% | 0.4% | 64 |
| 7 | 51.9% | 42.3% | 4.9% | 1.0% | 52 |
| 8 | 49.4% | 33.2% | 14.2% | 3.2% | 75 |

7 人局内奸胜率偏低，是已知问题。

各人数的身份分配（胜率与选型过程见 [`docs/DESIGN.md`](docs/DESIGN.md)）：

| 人数 | 身份 | 主公体力加成 |
|---|---|---|
| 5 | 主公、忠臣、反贼 ×2、内奸 | +1 |
| 6 | 主公、忠臣、反贼 ×2、内奸 ×2 | +1 |
| 7 | 主公、忠臣 ×2、反贼 ×3、内奸 | 无 |
| 8 | 主公、忠臣 ×2、反贼 ×3、内奸 ×2 | 无 |

武将按身份校正后的胜率在四种人数下基本都在 ±6% 以内。

1v1（40000 局）：先手 53.6%、后手 46.3%、平局 0.1%，回合数中位数 15；23 名可选武将的胜率都在 40–59% 之间。
